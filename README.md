# Agentic Data Analyst

Implementação do Desafio Técnico 1 para Engenheiro(a) de IA (Pleno): um assistente que investiga um banco SQLite a partir de perguntas de negócio em linguagem natural.

## Status

**Especificação aprovada. Implementação em andamento.**

## Tecnologias

- Python 3.12
- LangGraph
- LangChain
- FastAPI
- SQLite
- Streamlit
- pytest

A arquitetura e os critérios de aceite estão em [docs/SPEC-001-agentic-data-analyst.md](docs/SPEC-001-agentic-data-analyst.md).

O banco fornecido com o desafio não é versionado. Consulte [data/README.md](data/README.md) para preparar o ambiente local.
